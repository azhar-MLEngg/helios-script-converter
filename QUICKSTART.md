# Quick Start Guide

Get started with the Snowflake to StarRocks Conversion System in 5 minutes.

## Prerequisites

- Python 3.10+
- Anthropic API key ([Get one here](https://console.anthropic.com/))
- StarRocks instance (optional, for validation)

## Installation

### 1. Setup Environment

```bash
# Clone or navigate to the project
cd script-converter

# Create virtual environment
python -m venv venv
source venv/bin/activate  # Windows: venv\Scripts\activate

# Install dependencies
make install
# OR: pip install -r requirements.txt
```

### 2. Configure API Key

```bash
# Copy environment template
cp .env.example .env

# Edit .env and add your API key
# ANTHROPIC_API_KEY=sk-ant-...
```

### 3. Test Installation

```bash
# Validate connection (optional, requires StarRocks)
python main.py validate-connection

# Convert example script (without validation)
python main.py convert examples/snowflake_example.py --no-validate -v
```

## Basic Usage

### Convert a Script

```bash
python main.py convert input.py -o output.py
```

### Convert with Validation

```bash
# Requires StarRocks connection configured in .env
python main.py convert input.py -o output.py
```

### Convert a Single Query

```bash
python main.py convert-query "SELECT id::VARCHAR FROM users"
```

## Example Workflow

### 1. Create a Snowflake Script

Create `my_script.py`:
```python
import snowflake.connector

conn = snowflake.connector.connect(
    user='myuser',
    password='mypass',
    account='myaccount',
    warehouse='mywarehouse',
    database='mydb'
)

query = "SELECT id::VARCHAR, created_at::TIMESTAMP_NTZ FROM users"
cursor = conn.cursor()
cursor.execute(query)
```

### 2. Convert It

```bash
python main.py convert my_script.py -o my_script_starrocks.py --no-validate
```

### 3. Review Output

Check `my_script_starrocks.py`:
```python
# Converted from Snowflake to StarRocks
# Generated by Snowflake-to-StarRocks Conversion System

import pymysql

conn = pymysql.connect(
    host='localhost',
    port=9030,
    user='myuser',
    password='mypass',
    database='mydb'
)

query = "SELECT CAST(id AS VARCHAR), CAST(created_at AS DATETIME) FROM users"
cursor = conn.cursor()
cursor.execute(query)
```

## Configuration

### Minimal `.env` (No Validation)

```bash
ANTHROPIC_API_KEY=sk-ant-your-key-here
ENABLE_VALIDATION=false
```

### Full `.env` (With Validation)

```bash
ANTHROPIC_API_KEY=sk-ant-your-key-here
STARROCKS_HOST=localhost
STARROCKS_PORT=9030
STARROCKS_USER=root
STARROCKS_PASSWORD=
STARROCKS_DATABASE=test_db
ENABLE_VALIDATION=true
MAX_DEBUG_ITERATIONS=3
```

## Troubleshooting

### "ANTHROPIC_API_KEY not set"
- Add your API key to `.env` file
- Verify `.env` is in the project root

### "Connection validation failed"
- Check StarRocks is running
- Verify connection details in `.env`
- Use `--no-validate` to skip validation

### "Module not found"
- Activate virtual environment: `source venv/bin/activate`
- Install dependencies: `make install`
